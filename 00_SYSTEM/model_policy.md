# Маршрутизация моделей

Порядок предпочтения (раздел 10):

```
NO_LLM → LOCAL SCRIPT → LOCAL SEARCH → CHEAP MODEL → STANDARD MODEL → PREMIUM MODEL
```

- **NO_LLM / LOCAL SCRIPT** — хеширование, дедупликация, подсчёты, сортировка, обновление
  дашборда, генерация отчётов из уже собранных данных — всё это делают скрипты в
  `00_SYSTEM/scripts/` и `.claude/hooks/`, не модель.
- **LOCAL SEARCH** — точный поиск по файлу → локальный индекс → локальная БД → полнотекстовый
  локальный поиск → (если доступно) локальный векторный поиск.
- **CHEAP MODEL** — классификация, короткие резюме, рутинные QA-проверки.
- **STANDARD MODEL** — большинство агентских задач (контент, стратегия, анализ).
- **PREMIUM MODEL** — только по явной эскалации SKYLINE_MASTER для задач высокой ценности
  (P0/P1) — например, финальное стратегическое решение или сложный fact-check с
  противоречивыми источниками.

Эта установка выполняется в Cowork/Claude Code, где конкретная модель, обслуживающая сессию,
может отличаться от заявленной и меняться в рамках сессии — маршрутизация моделей не
гарантирует конкретный внешний бренд модели, а лишь задаёт **относительный уровень
"дешевизны" вызова** (меньше контекста / короче вывод / меньше инструментов для дешёвых
задач).
