# Ролевая матрица и модель разрешений

## Правило

Ни один агент не может молча взять на себя роль другого (раздел 34 спецификации).
По умолчанию — DENY BROAD ACCESS: каждый агент получает только необходимые инструменты.

Ни один агент автоматически не получает:
- неограниченную запись в файловую систему;
- неограниченный доступ в интернет;
- неограниченный shell;
- неограниченную публикацию;
- учётные данные.

Публикация и изменения инфраструктуры — привилегированные действия.

## Внешний шлюз (External Action Gate, раздел 66)

Перед любой внешней записью (публикация поста, изменение сайта, кампании) обязательна проверка:

1. правильный ли агент инициирует действие;
2. правильный ли scope;
3. контент утверждён (прошёл FINAL_GATEKEEPER: APPROVE);
4. учётные данные валидны;
5. цель верифицирована;
6. требуется ли ручное подтверждение человека;
7. доступен ли откат;
8. действие залогировано.

Если хотя бы один критический пункт не выполнен → **BLOCK**.
На данный момент (нет подключённых интеграций) — внешняя запись заблокирована для всех агентов.

## Дашборд

`127.0.0.1` / localhost. Публичный доступ не разрешён без явного изменения этой политики
пользователем. Секреты и учётные данные во фронтенде дашборда не отображаются.
