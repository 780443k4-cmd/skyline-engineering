# Токен-экономика

Владелец: TOKEN_GUARDIAN. Может наложить вето на расточительное выполнение, но не может менять
бизнес-стратегию.

## Иерархия исполнения (раздел 10)

```
NO_LLM → LOCAL SCRIPT → LOCAL SEARCH → CHEAP MODEL → STANDARD MODEL → PREMIUM MODEL
```

Премиальное рассуждение — исключение, а не правило.

## Чек-лист перед каждой задачей агента

1. Можно решить детерминированно (скриптом)? → решить скриптом, без LLM.
2. Можно решить локальными знаниями (01_KNOWLEDGE)? → не идти в облако/интернет.
3. Можно решить кэшем (09_CACHE)? → использовать кэш, если не устарел.
4. Достаточно дешёвой/малой модели? → не использовать премиальную.
5. Действительно ли нужен доступ в интернет/API? → если нет — не использовать.
6. Можно ли сократить вывод? → сократить.

## Лимиты по умолчанию (раздел 12)

| Параметр | Значение по умолчанию |
|---|---|
| MAX_TURNS на задачу агента | 3 |
| MAX_TOOL_CALLS на задачу агента | 5 |
| MAX_WEB_RESEARCH_CALLS на задачу | 3 |

Превышение лимита может разрешить только SKYLINE_MASTER для задачи высокой ценности.
При достижении лимита: STOP → сохранить частичный результат → вернуть MASTER. Никаких
бесконечных повторов.

## Что дашборд должен показывать (раздел H)

- количество выполненных задач;
- уровень модели (tier);
- оценка токенов;
- число облачных вызовов;
- число веб-вызовов;
- cache hits / cache misses;
- счётчик предотвращённых лишних вызовов;
- тренд оценочной стоимости.

Секреты никогда не отображаются.

## Рассмотренные и отклонённые сторонние инструменты (для памяти)

**OmniRoute** (`github.com/MrArtt/omniroute`, есть форки, напр. `diegosouzapw/OmniRoute`) —
локальный AI-шлюз, агрегирующий 231+ провайдеров ради бесплатных/дешёвых токенов
(заявлено ~1.6 млрd токенов/мес бесплатно), с авто-fallback, сжатием токенов и обходом
региональных блокировок.

Статус: **отклонён 2026-08-24** — найден CVE-2026-49352, механика инструмента построена
на обходе лимитов/оплаты провайдеров (риск нарушения ToS Anthropic и блокировки аккаунта),
плюс централизация API-ключей нескольких провайдеров через один локальный прокси. Прямо
противоречит правилу «использовать только официальные API» (см. `integrations.md`).

**Условие пересмотра:** вернуться к этому варианту, только если у SKYLINE реально возникнет
нехватка токенов/квоты по текущей (официальной) подписке Anthropic — тогда обсудить с
пользователем ещё раз перед подключением, а не подключать автоматически. Агент должен
напомнить пользователю об этой записи, если увидит признаки исчерпания квоты.

Также рассматривался и отклонён по аналогичным причинам (небезопасный локальный API без
аутентификации, утечка ключей в открытом виде) — **claude-mem** (`github.com/thedotmack/claude-mem`),
плагин персистентной памяти между сессиями. Функцию памяти в проекте и так покрывает
`01_KNOWLEDGE` + агент KNOWLEDGE_MANAGER.
