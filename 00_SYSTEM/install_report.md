## Хуки — установлены

`.claude/settings.json` + 4 детерминированных Python-скрипта в `.claude/hooks/`:

- `secret_scan.py` (PreToolUse на Write/Edit) — блокирует запись при обнаружении похожих
  на секреты строк. **Протестировано:** блокирует тестовый API-ключ (exit=2), пропускает
  обычный текст (exit=0).
- `audit_log.py` (PostToolUse) — детерминированно логирует событие в
  `08_AUDIT/agent_logs/events.jsonl`, редактирует (обрезает) содержимое, никогда не пишет
  секреты. **Протестировано:** запись успешно добавлена.
- `dashboard_update.py` — пересобирает `10_DASHBOARD/data/*.json` из состояния файловой
  системы, без LLM. **Протестировано:** сгенерировал все 6 JSON-файлов.
- `failed_task_capture.py` — переносит задачу в BLOCKED/FAILED с записью ошибки, без
  бесконечных повторов (retry максимум 1 раз для transient-ошибок).

## Разрешения

`00_SYSTEM/permissions.md` — полная ролевая матрица (раздел 34), External Action Gate
(раздел 66). SYSTEM_ADMIN — единственный агент, которому разрешено менять `.claude/**`.
FINAL_GATEKEEPER — единственный, кто может дать APPROVE на публикацию. Ни один агент не
получает по умолчанию неограниченный доступ к файлам/интернету/shell/публикации/секретам.

## Маршрутизация моделей и токен-политика

`00_SYSTEM/model_policy.md`, `00_SYSTEM/token_policy.md`: NO_LLM → LOCAL SCRIPT → LOCAL
SEARCH → CHEAP MODEL → STANDARD MODEL → PREMIUM MODEL. Лимиты по умолчанию: MAX_TURNS=3,
MAX_TOOL_CALLS=5, MAX_WEB_RESEARCH_CALLS=3 на задачу агента.

## Облачная политика

`00_SYSTEM/cloud_policy.md`: CLOUD_ACCESS = MINIMAL. Вся структурная/детерминированная
работа этой установки выполнена без вызовов модели для форматирования — только для
содержательных markdown-описаний (агенты/скиллы/политики), которые сами по себе являются
результатом задачи, а не техническим обвесом.

## Незавершённое / требует действия пользователя

1. **Перенос на диск C:.** Установка собрана в облачной рабочей области Cowork. Чтобы
   перенести её на компьютер (папка `C:\SKYLINE_LOCAL`), нужен один из двух шагов:
   - включить Computer Use в приложении Claude (я создам папку и запрошу доступ
     автоматически), или
   - создать пустую папку `C:\SKYLINE_LOCAL` вручную и сообщить об этом — я запрошу доступ
     через мост к устройству и перенесу все файлы.
2. **Реальные факты о компании** — Knowledge Library пуста (по требованию сценария —
   ничего не изобретено). Нужны материалы о Skyline Engineering ES.
3. **Интеграции** — сайт/CMS, Instagram/Facebook/TikTok, аналитика, CRM: нужно подтвердить
   платформы и подключить через настройки Claude.
4. **Утренний дашборд по расписанию** — будет настроен после подтверждения переноса на
   диск C: (см. отдельное сообщение).

## Следующие безопасные действия

- Предоставить документы/факты о компании → `knowledge-manager` внесёт их в библиотеку.
- Подтвердить платформу сайта и реальные соцсети/CRM → `system-admin` подключит коннекторы.
- Открыть `10_DASHBOARD/start_dashboard.bat` после переноса на компьютер, чтобы увидеть
  дашборд локально.
