## 4. Маркетинговый план и стратегия развития — актуализировано

Основа не меняется — 4 документа от 01.09.2026 остаются источником истины. Ниже — что остаётся
в силе без изменений, и что скорректировано с учётом реальных находок 13.09.2026.

### 4.1 Оффер и позиционирование (без изменений, актуально)

- **Категория:** не «строительная компания», а **Controlled Villa Delivery** — продукт
  **SKYLINE VILLA CONTROL SYSTEM™** (`positioning.md`, POS-001).
- **Формула:** проверка участка и реализуемости → бюджетная рамка → архитектура → инженерия →
  лицензирование → строительство → контроль качества → сдача, заказчик принимает решения,
  координацию берёт одна команда (POS-002).
- **Смысловое ядро:** «Не просто построить виллу. Сделать строительство управляемым.» Продаём
  управляемость, определённость, доказательство — в этом порядке (POS-003).
- **Главный враг коммуникации — неопределённость**, не конкурент (POS-005).
- **Трёхуровневая воронка предложений** (`marketing_strategy.md`, MKT-002): Private Villa
  Feasibility (низкий риск, продаёт ясность) → Design & Preconstruction → Full Villa Delivery.
- **Гарантии — только process guarantees**, никогда outcome (лицензия, доходность, ВНЖ — под
  запретом, MKT-003).

### 4.2 Аудитория (без изменений, актуально)

- **Языковой приоритет (AUD-002, решение владельца):** украинский основной → русский вторичный
  (диаспора в Европе, явно НЕ Россия) → Казахстан/СНГ низкий приоритет → EN/ES опционально.
- **ДНК клиента (AUD-003):** покупает контроль + предсказуемость + спокойствие, не квадратные
  метры. Сегменты по силе сигнала: P1 (есть конкретный участок) > P2 (состоятельная семья
  Зап./Сев. Европы со связью с Испанией) > P3 (предприниматель с капиталом из
  Украины/Польши/Чехии).
- **Анти-ДНК (AUD-004):** не квалифицировать бюджет ниже порога, срочный въезд за 1-3 месяца,
  запрос только бесплатного рендера, выбор по минимальной цене, нет участка/сценария,
  непрозрачные средства, попытку обойти KYC/санкции/налоги, ожидание гарантий ВНЖ/доходности.

### 4.3 Что скорректировано сегодня — на основе реальных находок

Это не смена стратегии, а операционная актуализация в свете диагностики AGT-01/AGT-03:

1. **SEO-приоритет №1 сместился на техническую нестыковку, не на новый контент.** Пока
   x-default/редирект сайта ведут на `/en`, а не `/uk`, вся остальная SEO-работа частично спорит
   сама с собой — сайт технически не подтверждает украинский как основной язык, хотя вся
   контент-стратегия построена именно на этом приоритете. **Рекомендация: это должно стать первой
   задачей AGT-01 в следующем реальном прогоне, раньше нового контента для SEO.**
2. **Facebook-канал недооценивался старой системой не по существу, а по ошибке проверки.**
   145 подписчиков и активная публикация — это рабочий, растущий канал, который стоит
   рассматривать наравне с Instagram при планировании контента, а не как второстепенный.
3. **TikTok — открытый стратегический вопрос, требует решения владельца, не техническое
   исправление.** Контент туда уходит регулярно (I, J, K), но канал физически не растёт (1
   подписчик). Варианты для решения Дениса: (а) продолжать публиковать по инерции без изменения
   подхода, (б) пересмотреть формат/частоту специально под TikTok, (в) снизить приоритет TikTok и
   перенаправить ресурс production на Instagram/Facebook, где аудитория реально есть. Система не
   принимает это решение сама — см. раздел 7.
4. **Google Business Profile остаётся самым дешёвым нереализованным рычагом** — не только для
   SEO (карточка компании, локальные цитирования), но и для контент-плана: он же был условием
   возврата вилл-концептов в план публикаций («вернутся, когда появятся первые отзывы через GBP»,
   `content_calendar.md`). Один нерешённый пункт блокирует два разных плана одновременно.

### 4.4 Новая ролевая ответственность (кто теперь ведёт стратегию)
