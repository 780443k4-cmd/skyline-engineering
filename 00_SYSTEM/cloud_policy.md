# Политика облачного доступа

Состояние по умолчанию: **CLOUD_ACCESS = MINIMAL**

## Облачный доступ разрешён только для

1. непосредственного вызова модели, необходимого для ответа на задачу;
2. явно необходимых внешних API;
3. свежего рыночного/поискового исследования;
4. получения внешней аналитики;
5. одобренной публикации в соцсетях;
6. одобренных операций с CMS.

## Облачный доступ НЕ разрешён просто для

- чтения локальных файлов без необходимости;
- повторения уже известного исследования;
- генерации общих идей;
- проверки уже верифицированных фактов;
- форматирования данных;
- вычислений;
- сортировки;
- фильтрации;
- локальных отчётов;
- обновления локального дашборда.

Где возможно — детерминированная работа выполняется локально без LLM (раздел 58).

## Минимизация данных перед вызовом модели (раздел 8)

1. классифицировать данные;
2. убрать нерелевантный контент;
3. убрать дубликаты;
4. убрать секреты;
5. убрать лишние персональные данные;
6. убрать несвязанные файлы проекта;
7. отправлять только релевантные выдержки;
8. предпочитать структурированные записи;
9. использовать кэшированный/стабильный контекст, где возможно.

**Вся библиотека знаний целиком никогда не отправляется модели.**

## Контекст задачи (раздел 11)

Автоматически НЕ включаются: весь репозиторий, вся Knowledge Library, вся история диалога,
весь сайт, вся история аналитики.

Используется TASK CONTEXT PACK: цель, релевантные факты, релевантные файлы, релевантные
метрики, ограничения, ожидаемый результат.
