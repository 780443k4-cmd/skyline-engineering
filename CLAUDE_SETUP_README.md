# Один последний шаг: активировать агентов/скиллы/команды

Все 15 агентов, 15 скиллов, 11 команд и хуки сейчас лежат в папке
`C:\SKYLINE_LOCAL\_claude_setup\`. Они не в папке `.claude`, потому что инструмент удалённой
записи файлов технически не может писать в папки с именем `.claude` на вашем компьютере (это
защита самого инструмента, не моя настройка) — а Claude Code ищет агентов/скиллы/команды
именно в `.claude\`.

## Что нужно сделать (30 секунд)

**Вариант 1 — через проводник:**
1. Откройте `C:\SKYLINE_LOCAL\`.
2. Переименуйте папку `_claude_setup` в `.claude` (правый клик → Переименовать →
   введите `.claude` и нажмите Enter — Windows позволяет имена, начинающиеся с точки, при
   переименовании существующей папки).

**Вариант 2 — через командную строку:**
```
cd C:\SKYLINE_LOCAL
ren _claude_setup .claude
```

После этого структура будет:
```
C:\SKYLINE_LOCAL\.claude\agents\      — 15 агентов
C:\SKYLINE_LOCAL\.claude\skills\      — 15 скиллов
C:\SKYLINE_LOCAL\.claude\commands\    — 11 команд /skyline-*
C:\SKYLINE_LOCAL\.claude\hooks\       — 4 локальных скрипта
C:\SKYLINE_LOCAL\.claude\settings.json
```

Откройте `C:\SKYLINE_LOCAL` как проект в Claude Code — агенты, скиллы и команды подхватятся
автоматически. Этот файл (`CLAUDE_SETUP_README.md`) после переименования можно удалить.
