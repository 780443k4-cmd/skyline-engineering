# SKILL: MARKET_CHECK

Часть общего набора из 15 переиспользуемых скиллов SKYLINE_LOCAL (раздел 62 спецификации).
Скиллы не считаются отдельными агентами и доступны всем 15 агентам в рамках их роли.

## PURPOSE

Не выдавать устаревшие данные за актуальные и не исследовать веб без необходимости.

## INPUT

Вопрос, требующий рыночных/актуальных данных.

## OUTPUT

Ответ с явной датой данных и статусом (кэш/свежее исследование), не более 2-5 источников.

## RULES

- Сначала — кэшированное исследование (`09_CACHE/research/`).
- Определить, устарели ли данные (см. EXPIRES в записи кэша).
- Целевое внешнее исследование — только если необходимо, и только по узкому вопросу.
- Сравнить несколько достоверных источников, зафиксировать дату каждого.
- Отделить факты от интерпретации. Не выдавать старые данные за текущие.

## STOP CONDITION

Как только достигнут порог достаточности доказательств (обычно 2-5 источников) — прекратить поиск.
