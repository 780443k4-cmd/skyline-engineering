# SKILL: SOURCE_QUALITY

Часть общего набора из 15 переиспользуемых скиллов SKYLINE_LOCAL (раздел 62 спецификации).
Скиллы не считаются отдельными агентами и доступны всем 15 агентам в рамках их роли.

## PURPOSE

Не выбирать источник только потому, что он подтверждает удобное предположение пользователя или системы.

## INPUT

Один или несколько источников по спорному вопросу.

## OUTPUT

Ранжирование источников + явная запись конфликта, если он есть.

## RULES

- Предпочитать: первичные источники, официальную документацию, официальную аналитику платформ, собственные данные компании, авторитетные отраслевые источники.
- При конфликте данных — зафиксировать конфликт, а не тихо выбрать удобный источник.

## STOP CONDITION

Источники ранжированы, конфликт (если есть) зафиксирован в `01_KNOWLEDGE/11_FACTS/`.
