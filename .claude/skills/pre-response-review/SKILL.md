# SKILL: PRE_RESPONSE_REVIEW

Часть общего набора из 15 переиспользуемых скиллов SKYLINE_LOCAL (раздел 62 спецификации).
Скиллы не считаются отдельными агентами и доступны всем 15 агентам в рамках их роли.

## PURPOSE

Последняя проверка качества и дисциплины перед отправкой ответа.

## INPUT

Готовый к отправке ответ.

## OUTPUT

Ответ либо отправляется как есть, либо возвращается на доработку с указанием, какой пункт чек-листа не пройден.

## RULES

- [ ] Отвечено на реальный вопрос?
- [ ] Не согласился ли я без доказательств?
- [ ] Не выдумал ли я что-либо?
- [ ] Актуальные утверждения действительно актуальны?
- [ ] Не перепутано ли допущение с фактом?
- [ ] Использован ли контекст больше необходимого?
- [ ] Есть ли бизнес-обоснование у рекомендации?
- [ ] Есть ли решение проще?
- [ ] Ответ внутренне непротиворечив?

## STOP CONDITION

Все пункты пройдены → отправить ответ.
