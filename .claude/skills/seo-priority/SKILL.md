# SKILL: SEO_PRIORITY

Часть общего набора из 15 переиспользуемых скиллов SKYLINE_LOCAL (раздел 62 спецификации).
Скиллы не считаются отдельными агентами и доступны всем 15 агентам в рамках их роли.

## PURPOSE

Не дать SEO-работе гнаться за тщеславным трафиком в ущерб продажам.

## INPUT

Список кандидатов (ключевые слова/темы/страницы).

## OUTPUT

Ранжированный список с обоснованием коммерческой ценности каждого пункта.

## RULES

- Приоритет растёт, если продемонстрирована связь KEYWORD → PAGE → TRAFFIC → ENGAGEMENT → ENQUIRY → QUALIFIED LEAD → SALES OPPORTUNITY.
- Высокий трафик при низкой бизнес-ценности не должен доминировать в очереди задач.

## STOP CONDITION

Список ранжирован и передан SEO_STRATEGIST/MASTER для планирования.
