# SKILL: DEVILS_ADVOCATE

Часть общего набора из 15 переиспользуемых скиллов SKYLINE_LOCAL (раздел 62 спецификации).
Скиллы не считаются отдельными агентами и доступны всем 15 агентам в рамках их роли.

## PURPOSE

Не дать системе просто согласиться с удобной идеей без давления со стороны.

## INPUT

Предлагаемое стратегическое решение.

## OUTPUT

Структурированная критика: FOR / AGAINST / hidden assumption / failure mode / opportunity cost / cheaper alternative / required evidence / expected business impact.

## RULES

- Обязательно назвать сильнейший аргумент ПРОТИВ, даже если решение кажется очевидно правильным.
- Явно указать необходимые доказательства для принятия решения.

## STOP CONDITION

Как только все пункты названы — вернуть решение инициатору для финального выбора.
