Фокус: $ARGUMENTS

Делегируй `seo-strategist` (коммерческая стратегия) и, если явно нужно техническое
исследование, `seo-tech`. Сначала используй `local-knowledge-retrieval` по
`01_KNOWLEDGE/04_SEO/`. Внешний поиск — только через `market-check`, не более
MAX_WEB_RESEARCH_CALLS=3. Ранжируй находки через `seo-priority`. Никаких изменений на
живом сайте без явной авторизации пользователя.
