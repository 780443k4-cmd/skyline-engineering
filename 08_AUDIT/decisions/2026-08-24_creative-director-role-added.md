# Решение: добавлена 16-я роль CREATIVE_DIRECTOR

**Дата**: 2026-08-24. **Инициатор**: владелец (Denis), после разбора качества постов B/D.

## Контекст

Разбор опубликованных постов B/D показал: визуальное исполнение (типографика на тёмном
фоне без единой фотографии) не было закреплено ни за одной из 15 ролей системы —
SOCIAL_CONTENT владеет структурой карусели (что на каком слайде), но не тем, как это
выглядит финально. Владелец попросил найти на GitHub готового "дизайн-агента", который
умеет: бренд-бук, шрифты, полные правила контента, сценарии для Reels, дизайн контента —
прежде чем повторять ту же ошибку.

## Исследование (WebSearch, 2026-08-24)

Просмотрены несколько коллекций Claude Code subagent'ов:
- `VoltAgent/awesome-claude-code-subagents`, `rshah515/claude-code-subagents`,
  `gensecaihq/Claude-Code-Subagents-Collection`, `lst97/claude-code-sub-agents` —
  в основном UI/software-дизайн (ui-designer для интерфейсов приложений), не под
  маркетинговый/социальный контент.
- **`stevenflanagan1/social-ai-team`** — лучшее совпадение: набор из 10 Claude Code
  skills под именно социальный контент, включая `brand-onboarding` (захватывает бренд
  с сайта/Instagram клиента, создаёт `context/brand-style.md`) и
  `social-creative-designer` (генерирует брендированные визуалы через image-gen MCP,
  4 режима: Generate/Composite/Brand overlay/Stop-Motion).
- Остальные найденные роли того репозитория (Content Calendar, Caption Writer,
  Publisher, Performance Review) дублируют уже существующие роли SKYLINE_LOCAL
  (CONTENT_ARCHITECT, SOCIAL_CONTENT, наша Zapier-публикация, SOCIAL_ANALYST) — импорт
  всего репозитория целиком не нужен, взят только недостающий паттерн.

## Решение

Не импортировать внешний репозиторий целиком (дублирует уже существующие роли и завязан
на инструменты, которых у нас нет — Playwright-скрейпинг, Blotato-планировщик). Вместо
этого — адаптирован только недостающий паттерн ("бренд-бук + владелец визуала") как
новая 16-я роль **CREATIVE_DIRECTOR** (`.claude/agents/creative-director.md`), владеющая:
- `01_COMPANY/brand.md` (бренд-бук: цвета/шрифты/лого/фото-стиль, как FACT-ы, не выдумки)
- `05_CONTENT/design_guidelines.md` (уже существовал, теперь имеет владельца)
- стандартом раскадровки Reels
- визуальной проверкой перед QUALITY_CONTROLLER

SOCIAL_CONTENT возвращён к исходному объёму (структура карусели, без визуального
исполнения — это было временное решение того же дня, тут же исправлено).

## Инструменты для реального визуала — найдено, НЕ подключено

Проверен реестр MCP-коннекторов организации: доступны, но не подключены пользователем —
**Canva** (поиск/создание/экспорт дизайнов), **Adobe for creativity** (включая
`asset_get_brand_color_themes` — управление реальным брендовым набором), **Figma**
(design system rules). Ни аналог "Nano Banana" image-gen MCP из внешнего репозитория
в реестре не найден. Рекомендация: подключить Canva как самый быстрый путь к реальным
брендированным визуалам вместо типографской заглушки — решение за пользователем
(подключение коннектора делается через настройки Claude, не отсюда).
