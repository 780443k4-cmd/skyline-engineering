# Индекс решений (короткий код → файл)

Один короткий код на каждое решение проектного масштаба. Владелец может сослаться на
код или на дату вместо пересказа контекста — ассистент сначала читает ЭТОТ файл (он
маленький и остаётся маленьким, даже когда `08_AUDIT/decisions/` вырастет до сотен
файлов), а не всю историю чата и не всю базу знаний.

Формат кода: `DEC-NNN`, по возрастанию, не переиспользовать номера.

## Как этим пользоваться

- Владелец: "глянь DEC-004" или "что решили 1 сентября про стратегию" — этого
  достаточно, пересказывать контекст не нужно.
- Ассистент: при любом вопросе "почему у нас так", "что решили", "мы это обсуждали?" —
  сначала grep/чтение этого файла (секунды, не растёт линейно с историей), потом
  (если нужны детали) — конкретный файл решения по ссылке. Полная база знаний или чат
  перечитываются только если в этом индексе действительно ничего нет по теме.
- Каждое решение проектного масштаба (не рутинная правка) добавляется сюда СРАЗУ, в
  момент принятия — не задним числом. Если пропущено — восстанавливается по первому
  требованию, как это было сделано для DEC-004.
