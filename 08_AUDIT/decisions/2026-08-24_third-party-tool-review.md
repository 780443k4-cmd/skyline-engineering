## Инструмент 1: claude-mem
- **INPUT_REFERENCE**: github.com/thedotmack/claude-mem
- **STATUS**: ОТКЛОНЁН
- Персистентная память между сессиями Claude Code — функционально дублирует
  `01_KNOWLEDGE` + агента KNOWLEDGE_MANAGER.
- Публичный security audit (issue #1251): 17 уязвимостей, 4 критические — в т.ч.
  неаутентифицированный локальный HTTP API (порт 37777), отдающий сохранённые промпты,
  код и API-ключи открытым текстом; path traversal. Мейнтейнер публично не отреагировал.

## Инструмент 2: OmniRoute
- **INPUT_REFERENCE**: github.com/MrArtt/omniroute (форки: diegosouzapw/OmniRoute и др.)
- **STATUS**: ОТКЛОНЁН, с условием пересмотра
- Локальный AI-шлюз, агрегирующий 231+ провайдеров ради бесплатных/дешёвых токенов
  (~1.6 млрд токенов/мес заявлено), с fallback между провайдерами и обходом
  региональных блокировок.
- Найден CVE-2026-49352. Механика инструмента построена на обходе лимитов/оплаты
  провайдеров — риск нарушения ToS Anthropic. Централизует API-ключи нескольких
  провайдеров через один локальный прокси. Прямо противоречит правилу «только
  официальные API» (`00_SYSTEM/integrations.md`).
- **Условие пересмотра**: вернуться к обсуждению, только если у SKYLINE реально
  возникнет нехватка токенов/квоты по официальной подписке Anthropic — не подключать
  автоматически, обсудить с пользователем заранее. Агент должен напомнить пользователю
  об этой записи при признаках исчерпания квоты (см. `00_SYSTEM/token_policy.md`,
  раздел "Рассмотренные и отклонённые сторонние инструменты").

- **OUTPUT_REFERENCE**: `00_SYSTEM/token_policy.md` (раздел добавлен), этот файл.
- **RESULT**: Оба инструмента не подключены. Решение зафиксировано для будущих сессий.
