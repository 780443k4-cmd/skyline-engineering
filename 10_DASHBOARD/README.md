# SKYLINE_LOCAL — локальный дашборд

## Запуск (Windows)

1. Откройте папку `SKYLINE_LOCAL\10_DASHBOARD\`.
2. Дважды кликните **start_dashboard.bat**.
3. Браузер откроется на `http://127.0.0.1:8787/app/index.html`.

Требуется установленный Python 3 (python.org) — ничего больше устанавливать не нужно,
дашборд не использует внешние зависимости и не обращается в интернет.

## Обновление данных

Дашборд читает статические JSON-файлы из `10_DASHBOARD/data/`. Чтобы обновить их
вручную:

```
python .claude/hooks/dashboard_update.py
```

(запускать из корня `SKYLINE_LOCAL/`). Это чисто детерминированный скрипт — он не
вызывает модель и ничего не отправляет в облако.

В обычной работе агенты (в первую очередь `system-admin` и скилл `dashboard-update`)
вызывают этот скрипт после значимых изменений состояния (задача перемещена, факт
добавлен, аналитика обновлена).

## Безопасность

- Сервер слушает только `127.0.0.1` — недоступен с других устройств в сети.
- Секреты и учётные данные никогда не пишутся в файлы `10_DASHBOARD/data/`.
- Остановить сервер — закрыть окно или Ctrl+C.
