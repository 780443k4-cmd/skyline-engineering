# SKYLINE Engineering — деплой сайта

**Хостинг: Vercel.** Домен `skylineengineering.es` подключён к Vercel и деплоится
автоматически при каждом `git push` в ветку `main`. Без SSH, без секретов, без
ручных шагов на сервере.

## Как это работает

1. Правки пушатся в GitHub, репозиторий `780443k4-cmd/skyline-engineering`, ветка `main`.
2. Vercel подключён к репозиторию через GitHub-интеграцию и сам подхватывает
   каждый пуш (webhook) — собирает и выкладывает новую версию, обычно за 1-3 минуты.
3. Статус деплоя смотреть на `vercel.com` (проект в аккаунте, к которому привязан
   домен) или на вкладке **Deployments** в самом GitHub-репозитории.
4. Для деплоя не нужны: GitHub Actions, SSH-ключи, серверные секреты, ручной вход
   куда-либо.

## Hetzner-сервер (167.233.221.39) БОЛЬШЕ НЕ ИСПОЛЬЗУЕТСЯ

До 2026-09-01 сайт разворачивался через SSH на сервере Hetzner (nginx + systemd
сервис `skyline`). С переходом на Vercel это полностью заброшено. Сервер, даже
если ещё существует, на живой сайт никак не влияет.

**Если сайт не обновился после пуша — причина в Vercel (смотреть его дашборд и
логи сборки), а не в SSH/Hetzner.** Не создавать заново workflow с деплоем на
Hetzner, не искать и не чинить секреты `HETZNER_SSH_*` — эта ветка инфраструктуры
закрыта.
