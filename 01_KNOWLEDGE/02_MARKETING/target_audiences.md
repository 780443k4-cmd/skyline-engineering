## DNA клиента (FACT — прямая формула источника)

```
ХОЧУ: свой дом + Испания + семья + качество жизни + долгосрочный актив
НО БОЮСЬ: ошибки + перерасхода + подрядчиков + лицензий + потери контроля
ПОЭТОМУ: ищу информацию + сравниваю + проверяю + ищу доказательства
Я ПОКУПАЮ: не строительство, а КОНТРОЛЬ + ПРЕДСКАЗУЕМОСТЬ + СПОКОЙСТВИЕ
```

Клиент — не «богатый украинец/русскоязычный». Язык/национальность — слой коммуникации, а
не proxy платёжеспособности (FACT: это явно отвергнутое допущение в DNA-документе, п.1.1).
Точная модель: `страна проживания × источник капитала × связь с Испанией × стадия проекта ×
потребность в custom build`.

Порог продукта: **от €400 000 на строительство** (земля и часть расходов — отдельно).

## Anti-DNA / антисегменты (не квалифицировать, не тратить бюджет)

Бюджет ниже порога продукта; срочный въезд 1–3 мес.; ищет только бесплатный рендер/проект;
выбирает исключительно по минимальной цене за м²; нет участка и конкретного сценария; нет
понятного источника средств/банковского маршрута; попытка обойти KYC/санкции/налоги; ожидание
гарантированного ВНЖ (golden visa отменена в Испании с 03.04.2025 — FACT) или гарантированной
доходности; нерешённый конфликт супругов по стране/бюджету/назначению дома.

## JTBD (ранжированы по силе сигнала, из DNA §15 + JTBD §9)

1. **Превратить конкретный участок в реализуемый семейный дом** — самый сильный сигнал стадии.
2. Создать второй дом, управляемый из другой страны — не превратить стройку в тревогу.
3. Создать семейную базу/актив в ЕС — вернуть ощущение долгосрочного контроля.
4. Убрать компромиссы готового рынка — закрыть бесконечный поиск.
5. Разместить капитал в понятном материальном проекте.

## Главные страхи (по силе, DNA §6)

Потеря контроля (дистанция) → неправильный участок → неуправляемый бюджет → подрядчики
перекладывают ответственность друг на друга → стройка станет «второй работой».
**Гипотеза источника (не факт):** неопределённость теряет клиентов чаще, чем headline price.

## Что клиент реально покупает (5 уровней, DNA §8)

вилла → индивидуальный дом → решение семейной задачи → контроль над трансграничным проектом →
**спокойствие**, что решение находится в руках системы, а не случайного подрядчика.
