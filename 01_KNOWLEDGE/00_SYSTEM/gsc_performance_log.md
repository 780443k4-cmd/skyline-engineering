## Диагноз (вывод, не факт с сайта — интерпретация KNOWLEDGE_MANAGER на основе цифр выше)

- Сайт практически не виден по коммерческим запросам: страница `/en/villas` получает много
  показов (35) но позиция ~78 (8-я+ страница выдачи) — это ключевая техническая/контентная
  проблема, не проблема спроса. Совпадает с тем, что мы уже начали чинить (Schema.org, meta,
  внутренняя перелинковка).
- Реальные клики (2 из 73 показов) идут в основном по брендовым/навигационным запросам
  (skyline, sky line, engineering) и на главную/about/legal — не по темам "villa architect
  costa blanca" и т.п., где сайт есть в индексе, но глубоко в выдаче.
- Десктоп ранжируется хуже мобильного — стоит проверить десктопную версию отдельно
  (скорость, Core Web Vitals) на следующем техническом проходе.
- Это первый снимок при почти нулевой оптимизации — базовая точка отсчёта (baseline) для
  сравнения с будущими снимками после внедрения технических правок.

## Как использовать

- Следующий снимок добавлять сюда же новым разделом `## Снимок <дата>`, не затирая предыдущие —
  это журнал, а не текущее состояние.
- Сравнивать позицию/показы `/en/villas` и других страниц между снимками — это главный
  индикатор, работает ли техническая SEO-часть.
